```bash

  "scripts": {
    "dev": "vite --port 5180",

    "preview": "vite preview"
  },
  "dependencies": {
    "@supabase/supabase-js": "^2.99.0",
    "grapesjs": "^0.22.7",
    "grapesjs-blocks-basic": "^1.0.2",
    "grapesjs-plugin-forms": "^2.0.6",
    "sortablejs": "^1.15.7",
    "sweetalert2": "^11.0.0"
  },
  "devDependencies": {
    "@tailwindcss/vite": "^4.1.18",
    "autoprefixer": "^10.4.24",
    "postcss": "^8.5.6",
    "tailwindcss": "^4.1.18",
    "vite": "^5.4.0"
  }
}
EOF

# Create vite.config.js
cat > apps/remix-go/vite.config.js << 'EOF'
import { defineConfig } from 'vite';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  plugins: [tailwindcss()],
  server: { port: 5180 },

EOF

# Create index.html
cat > apps/remix-go/index.html << 'EOF'
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Remix Go - AI Video Editor</title>
  <link rel="stylesheet" href="/src/style.css">
</head>
<body>
  <div id="app"></div>
  <script type="module" src="/src/main.js"></script>
</body>
</html>
EOF

# Create style.css
cat > apps/remix-go/src/style.css << 'EOF'
@import "tailwindcss";
@import "grapesjs/dist/css/grapes.min.css";
EOF

# Create main.js
cat > apps/remix-go/src/main.js << 'EOF'
document.addEventListener('DOMContentLoaded', () => {
  const app = document.getElementById('app');
  app.innerHTML = '<h1 class="text-white text-4xl p-8">Remix Go - Loading...</h1>';

cd apps/remix-go && npm install

npm run dev
```

### Verify It Works
1. Open `http://localhost:5180` in browser
2. You should see "Remix Go - Loading..."
3. If it works, scaffold is ready — proceed to Phase 2

### Phase 3: Remove Server Dependencies

For each extracted file, remove/replace:

## Higgsfield Integration: New Standalone App

**CRITICAL**: This does NOT modify any existing Higgsfield code. It creates a new self-contained app at `apps/remix-go/`, following the same pattern as `apps/director/` and `apps/vimax/`.

### Higgsfield App Pattern

Higgsfield has two extension types:
- **`apps/`** — Standalone sub-apps (director, vimax) with their own package.json, frontend, backend
- **`modules/`** — External git submodules (CineGen, LTX-Desktop, rendiv)

We use the `apps/` pattern since this is a self-contained vanilla JS + Vite app.

## Personalization Tokens Without Social APIs

### All Available Tokens

| Token | Description | Example Output |
|-------|-------------|----------------|
| `FIRSTNAME` | First name | `John` |
| `LASTNAME` | Last name | `Smith` |
| `NAME` | Full name | `John Smith` |
| `EMAIL` | Email address | `john@example.com` |
| `GENDER` | Gender | `Male` |
| `GEOCOUNTRY` | Country (from IP) | `United States` |
| `GEOCITY` | City (from IP) | `New York` |
| `GEOSTATE` | State/region (from IP) | `California` |
| `CUSTOM` | User-defined token | Any value |

### Token Modes (Syntax)

| Mode | Syntax | Example | Output |
|------|--------|---------|--------|
| **Plain** | `{{TOKEN}}` | `{{FIRSTNAME}}` | `John` |
| **Uppercase** | `{{up TOKEN}}` | `{{up FIRSTNAME}}` | `JOHN` |
| **Fallback** | `{{d TOKEN "default"}}` | `{{d FIRSTNAME "Friend"}}` | `John` or `Friend` if empty |

### How Users Add Tokens in the Editor

**Current flow** (from `Personalizer.js`):

```
1. User is editing a text overlay in the video editor
2. User clicks "Personalizer" button in the actions sidebar
3. A popup opens showing the token selector:
   
   ┌──────────────────────────────────────────────┐
   │  Select Token          │  Configure           │
   │                        │                      │
   │  ● FIRSTNAME           │  FIRSTNAME           │
   │  ○ LASTNAME            │  ─────────────────   │
   │  ○ EMAIL               │  ● plain             │
   │  ○ GEOCOUNTRY          │  ○ Fallback: [____]  │
   │  ○ GEOCITY             │  ○ UPPERCASE         │
   │  ○ GEOSTATE            │                      │
   │  ○ NAME                │  [Add] button        │
   │  ○ GENDER              │                      │
   │  ○ CUSTOM: [______]    │                      │
   └──────────────────────────────────────────────┘

4. User selects token + mode, clicks "Add"
5. Token string (e.g., `{{FIRSTNAME}}`) is inserted at cursor position
   in the text overlay they were editing
```

**Implementation** (`src/components/Personalizer.js`):
```javascript
export function Personalizer({ onTokenChosen }) {
  const TOKENS = ['FIRSTNAME', 'LASTNAME', 'EMAIL', 'GEOCOUNTRY', 
                  'GEOCITY', 'GEOSTATE', 'NAME', 'GENDER', 'CUSTOM'];
  
  const MODES = {
    PLAIN: (token) => `{{${token}}}`,
```

**Step 3: Email campaign builds personalized URL**

Each email provider has a `paramsBuilder` that converts tokens to provider-specific merge tags:

| Provider | Token | URL Parameter |
|----------|-------|---------------|
| **MailChimp** | `FIRSTNAME` | `FIRSTNAME=*|FNAME|*` |
| **AWeber** | `FIRSTNAME` | `FIRSTNAME={!firstname}` |
| **Interspire** | `FIRSTNAME` | `FIRSTNAME=%%First Name%%` |
| **GetResponse** | `FIRSTNAME` | `FIRSTNAME=[[firstname]]` |
| **Infusionsoft** | `FIRSTNAME` | `FIRSTNAME=~Contact.FirstName~` |
| **Sendlane** | `FIRSTNAME` | `FIRSTNAME=VAR_FIRST_NAME` |
| **Constant Contact** | `FIRSTNAME` | `FIRSTNAME={!$Subscriber.Firstname}` |
| **SendReach** | `FIRSTNAME` | `FIRSTNAME=[FNAME]` |
| **Custom** | `FIRSTNAME` | `FIRSTNAME=firstname_token` |

**Example final URL** (MailChimp):
```
https://video.example.com?id=xxx&FIRSTNAME=*|FNAME|*&EMAIL=*|EMAIL|*
```

MailChimp replaces `*|FNAME|*` with the subscriber's actual first name before sending.

**Step 4: Embed code passes params to iframe**

```html
<!-- The embed code on the user's website -->
<iframe id='vr-xxx' src='https://video.example.com?id=xxx' ...></iframe>
<script>
  // Read params from hosting page URL
  var params = window.location.search.substring(1);
  // Pass them to the video iframe
  document.getElementById('vr-xxx').src += '&' + params;
</script>
```

If the hosting page URL is `https://mysite.com?FIRSTNAME=John&EMAIL=john@example.com`, the iframe URL becomes:
```
https://video.example.com?id=xxx&FIRSTNAME=John&EMAIL=john@example.com
```

**Step 6: Token replacement in text overlays**

```javascript
// src/lib/tokenReplacer.js
function replaceTokens(text, tokenValues) {
  return text
    // Handle uppercase: {{up FIRSTNAME}}
    .replace(/\{\{up (\w+)\}\}/g, (_, token) => 
      (tokenValues[token] || '').toUpperCase())
    // Handle fallback: {{d FIRSTNAME "Friend"}}
    .replace(/\{\{d (\w+) "([^"]*)"\}\}/g, (_, token, defaultVal) => 
      tokenValues[token] || defaultVal)
    // Handle plain: {{FIRSTNAME}}
    .replace(/\{\{(\w+)\}\}/g, (_, token) => 
      tokenValues[token] || '');
}

// Input:  "Hello {{FIRSTNAME}}, welcome to {{up GEOCITY}}!"
// Params: { FIRSTNAME: "John", GEOCITY: "New York" }
```

## SendSpark Feature Mapping to Higgsfield AI

### What SendSpark ACTUALLY Does

SendSpark's core workflow is NOT "generate video from text." It's:
1. **Record ONE video** saying "Hi [FIRST NAME]" as a placeholder
2. **AI clones your face/voice** and replaces the placeholder with each prospect's name
3. **Generate 100+ personalized versions** from that one recording
4. **Dynamic backgrounds** with prospect's website/LinkedIn
5. **Deliver via CRM/email platforms** at scale

This requires **AI face cloning + voice cloning + lip sync** — not text-to-video generation.

```javascript
// src/lib/pageshot.js
const PAGESHOT_BASE = 'https://pageshot.site/v1';

// Single screenshot
async function captureWebsite(url, options = {}) {
  const response = await fetch(`${PAGESHOT_BASE}/screenshot`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      url,
      width: options.width || 1920,
      height: options.height || 1080,
      format: 'png',
      full_page: false,
      block_ads: true,
      hide_banners: true,
      delay: 2000,
      response: 'json',
    }),
  });
  const data = await response.json();
  return data.data.image; // base64 data URL
}

// Batch screenshots (up to 5 URLs)
async function captureBatch(urls, options = {}) {
  const response = await fetch(`${PAGESHOT_BASE}/screenshot/batch`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      urls,
      width: options.width || 1920,
      height: options.height || 1080,
      format: 'png',
    }),
  });
  const data = await response.json();
  return data.results; // array of { url, success, data: { image, ... } }
}
```

```javascript
export function tokenPlugin(editor) {
  // Add token insertion command
  editor.Commands.add('insert-token', {
    run(editor, sender, { token }) {
      const selected = editor.getSelected();
      if (selected) {
        const currentText = selected.components().models[0]?.get('content') || '';
        selected.components(`${currentText}{{${token}}}`);
        selected.addAttributes({ 'data-token': token });
      }

  editor.Panels.addButton('views', {
    id: 'tokens',
    className: 'fa fa-code',
    command: 'open-token-panel',

  });
```

```javascript
// src/lib/grapesjs/export.js
export function exportPage(editor, tokenValues = {}) {
  let html = editor.getHtml();
  let css = editor.getCss();

  // Replace {{TOKEN}} with values (for preview)
  Object.entries(tokenValues).forEach(([key, value]) => {
    const regex = new RegExp(`\\{\\{${key}\\}\\}`, 'g');
    html = html.replace(regex, value || '');
  });

  return { html, css };
}

// For published page (no substitution — tokens resolved at runtime via URL params)
export function exportPageWithTokenSupport(editor) {
  const html = editor.getHtml();
  const css = editor.getCss();
  
  // Add token replacement script
  const tokenScript = `
    <script>
      (function() {
        const params = new URLSearchParams(window.location.search);
        document.querySelectorAll('[data-token]').forEach(el => {
          const token = el.getAttribute('data-token');
          const value = params.get(token) || el.getAttribute('data-default') || '';
          if (el.tagName === 'IMG') el.src = value;
          else if (el.tagName === 'A') el.href = value;
          else if (el.tagName === 'VIDEO') el.src = value;
          else el.textContent = el.textContent.replace('{{' + token + '}}', value);
        });
      })();
    </script>
  `;
  
  return { html: html + tokenScript, css };
}
```

## Hybrid Architecture: AI Generation + Popcorn.js Overlays

### How the Hybrid Workflow Works

```
Step 1: GENERATE (AI)
┌─────────────────────────────────────────────┐
│  User enters prompt + selects AI model      │
│  ┌─────────────────────────────────────┐    │
│  │  Muapi.generateVideo()              │    │
│  │  OR Muapi.generateImage() → I2V     │    │
│  │  OR Muapi.generateI2V()             │    │
│  └─────────────────────────────────────┘    │
│  AI generates base video (5-15 seconds)     │
└─────────────────────────────────────────────┘
                    │
                    ▼
Step 2: EDIT (Popcorn.js)
┌─────────────────────────────────────────────┐
│  Video plays in Popcorn.js player           │
│  User adds interactive overlays:            │
│  • Lead capture forms (personalized)        │
│  • Text overlays with animations            │
│  • Image/logo overlays                      │
│  • CTA buttons (clickable)                  │
│  • Popup overlays                           │
│  • Personalization tokens ({{NAME}}, etc.)  │
└─────────────────────────────────────────────┘
                    │
                    ▼
Step 3: PUBLISH
┌─────────────────────────────────────────────┐
│  Generate embed code with overlays          │
│  Email campaign personalized links          │
│  Social sharing (if enabled)                │
│  Retarget embed code                        │
└─────────────────────────────────────────────┘
```

### AI Integration Points in the App

| Step | AI Method | What It Does |
|------|-----------|-------------|
| Getting Started | `muapi.generateVideo()` | Generate base video from text prompt |
| Getting Started | `muapi.generateImage()` → `muapi.generateI2V()` | Generate image, then animate it |
| Getting Started | `muapi.generateI2V()` | Animate uploaded image into video |
| Editor | `muapi.generateImage()` | Generate overlay images/text |
| Editor | `muapi.generateI2I()` | Transform/upscale images in editor |
| Editor | `muapi.generateAudio()` | Generate background music |
| Editor | `muapi.generateText()` | Generate niche scripts/prompts |
| Editor | `muapi.processVideoTool()` | Process video (watermark removal, etc.) |

### Popcorn.js Overlays (What AI Can't Do)

These are the interactive elements that require DOM manipulation:

| Overlay | Why Popcorn.js (Not AI) |
|---------|------------------------|
| **Lead capture form** | Needs to capture real user input (email, name) and POST to webhook |
| **Clickable CTA** | Needs real click handlers to redirect to URLs |
| **Personalization tokens** | `{{NAME}}`, `{{EMAIL}}` get replaced at playback time from URL params |
| **Pause at CTA** | Video pauses at specific time for user interaction |
| **Popup overlay** | Appears at specific timestamp, dismissible by user |
